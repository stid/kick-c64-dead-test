## What this is

KickAssembler for hardware repair and historical preservation.

## This implementation

**stid and contributors.** The KickAssembler source, the RAM test methodology introduced in
2.0 (AA/55/PRN and walking-bit patterns), the SID filter test, color bars, chip-level failure
reporting, build system and documentation are original work.
